3. LOKAL GESPEICHERTE DATEN

Orbit speichert nur auf Ihrem Gerät (Windows: %APPDATA%\Orbit; Linux: ~/.config/Orbit und

  - ggf. eine aktualisierte Kopie von yt-dlp im Unterordner "tools",
  - eine Protokolldatei mit technischen Meldungen zur Fehlersuche,
  - ein Proxy-Passwort, falls gesetzt, verschlüsselt für Ihr Benutzerkonto (Windows: DPAPI;
    Linux: AES-256-GCM mit einer nur für Ihr Konto lesbaren Schlüsseldatei),
  - Browser-Cookies, die die Erweiterung übergibt (Abschnitt 4), nur bis der jeweilige
    Download fertig ist; danach werden sie gelöscht,
  - beim Fernzugriff (Abschnitt 5) einen gesalzenen Hash Ihres Passworts.

Diese Daten verarbeite ich nicht; sie liegen allein bei Ihnen. Sie werden beim Löschen des
Datenordners entfernt (die Deinstallation bietet das an; unter Linux "uninstall.sh --purge").

4. BROWSER-ERWEITERUNG UND ZWISCHENABLAGE

Die optionale Browser-Erweiterung übergibt einen Download direkt an Orbit auf demselben Gerät
(Native Messaging, lokale Verbindung nur für Ihr Benutzerkonto): Link, Adresse der Seite,
User-Agent, vorgeschlagenen Dateinamen und, nur wenn Sie es in der Erweiterung erlauben, die
Cookies für diesen Link. Orbit sendet diese Cookies nur an die Website, zu der sie gehören.
Ist die Überwachung der Zwischenablage eingeschaltet, prüft Orbit kopierten Text auf
Download-Links; der Text wird nicht gespeichert.

5. FERNZUGRIFF (OPTIONAL, STANDARDMÄSSIG AUS)

Der Fernzugriff startet einen kleinen Webserver, der nur auf Ihrem eigenen Gerät
(127.0.0.1) lauscht. Orbit öffnet ihn nicht selbst ins Netzwerk oder Internet. Machen Sie
ihn über einen eigenen Tunnel- oder Weiterleitungsdienst erreichbar, gelten dessen

This Privacy Policy describes what data Orbit Download Manager ("Orbit", "the Software")
stores and transmits, and what it does not. The publisher and controller is named in
section 7.

1. NO TELEMETRY, NO ACCOUNTS

Orbit does not require an account or sign-in, does not collect analytics or usage
statistics, and does not contain any advertising or tracking SDKs. Apart from the optional
update checks described in Section 5, Orbit does not contact any server operated by the
publisher.

2. DATA STORED LOCALLY ON YOUR DEVICE

To function, Orbit stores the following data locally, in your per-user application data
folder (on Windows: %APPDATA%\Orbit; on Linux: ~/.config/Orbit for settings and
~/.local/share/orbit for everything else; in portable mode on either system: a "Data" folder
next to the Orbit program), and never transmits it to the publisher:

  - Application settings (theme, download directory, connection limits, schedule, proxy).
  - Your list of downloads and their state, so in-progress transfers can resume after the
    application is closed and reopened.
  - A resume-metadata sidecar file next to each partially downloaded file, recording which
    byte ranges have already been written.
  - For BitTorrent transfers, a cache of the DHT (Distributed Hash Table) routing table, so
    peer discovery does not have to restart from scratch on every launch.
  - An updated copy of yt-dlp, if Orbit has downloaded one (see Section 5), in a "tools"
    subfolder.
  - A local log file containing diagnostic messages (connection attempts, errors), useful
    for troubleshooting. This log never leaves your device unless you choose to share it
    yourself.
  - If you set a proxy password, it is stored encrypted for your user account (on Windows
    with the Windows Data Protection API; on Linux with a key file in the folder above
    that only your user account can read).
  - Browser cookies handed over by the Orbit browser extension (see Section 3) are kept with
    the download they belong to until it has finished, and are then deleted.

Backups you export from Settings contain your settings and, if you choose, your download
list. They never contain passwords or browser cookies.

Uninstalling Orbit through Windows "Apps & features" removes the installed program files.
You may separately delete %APPDATA%\Orbit to remove the data described above; the
uninstaller will offer to do this for you. On Linux, ~/.local/lib/orbit/uninstall.sh removes
the program files, and "uninstall.sh --purge" also removes the data described above.

3. BROWSER EXTENSION AND CLIPBOARD

The optional Orbit browser extension sends a download you hand to Orbit directly to Orbit on
the same device, through the browser's native messaging feature and a local connection that
only your user account can use. For each download it sends the link, the address of
the page it came from, your browser's user agent, the file name the browser suggested and,
only if you have allowed it in the extension, the browser's cookies for that link, so
downloads that need you to be signed in work. Orbit uses these cookies only for requests to
the website they belong to and does not send them anywhere else.

When clipboard monitoring is turned on (Settings > General), Orbit reads text you copy in
other applications to look for download links. The text is not stored, and nothing is
downloaded unless you choose to.

4. REMOTE / WEB ACCESS (OPTIONAL)

Orbit includes an optional Remote Access feature, disabled by default, that lets you manage
your downloads from a phone or other device through a browser. When you enable it in
Settings and set a password:

  - Orbit stores a salted hash of that password on your device (never the plaintext
    password) alongside the other application settings described in Section 2.
  - Orbit starts a small web server that listens only on your own device
    (127.0.0.1/localhost) on the port you choose. Orbit does not open this server to your
    network or the internet by itself; reaching it from another device is only possible if
    you separately set up a tunnel or forwarding tool of your own choosing, which is outside
    Orbit's control.
  - A short-lived session cookie is issued to your browser after you log in, and is used only
    to authenticate requests to this local server.

Disabling Remote Access stops the server; deleting the stored password from Settings removes
the saved password hash.

5. NETWORK CONNECTIONS

Orbit makes network connections only to addresses you direct it to, or that are a direct
consequence of a transfer you started, plus the update checks below:

  - HTTP(S) downloads: to the URL you provide.
  - Media downloads: to the website of the link you provide, through yt-dlp (bundled with
    Orbit on Windows; on Linux, the copy installed on your system).
  - BitTorrent: to trackers referenced by a torrent or magnet link you add, to a
    supplementary list of well-known public trackers (added only for torrents that are not
    marked private, to widen peer discovery), to the public BitTorrent DHT network, and to
    other peers in a torrent's swarm, as is inherent to how the BitTorrent protocol works.
    While a torrent is active, Orbit may also upload pieces of that torrent's data to other
    peers (this is normal BitTorrent "seeding" behavior, not a separate data-sharing
    feature).
  - Update check: shortly after launch and every few hours, Orbit downloads a small file
    describing the latest version from the Orbit website. The request contains no personal
    data beyond what any web request reveals (such as your IP address). You can turn it off
    in Settings > About. If you choose to install an update, the installer is downloaded
    from the address listed in that file.
  - yt-dlp updates: about once a day, and after a media download fails, Orbit asks GitHub
    (api.github.com) for the latest release of the open-source yt-dlp project and, when a
    newer one exists, downloads it and its published checksum list from github.com. The
    request contains no personal data beyond what any web request reveals (such as your IP
    address), and GitHub's own privacy statement applies to it. You can turn it off in
    Settings > Media.
  - If you configure a proxy in Settings > Network, these connections go through that proxy.

Orbit does not send your download history, file names, or any other locally stored data to
the publisher or to any third party.

6. THIRD-PARTY COMPONENTS

Orbit is built on open-source components (Qt, libcurl, OpenSSL, libtorrent-rasterbar,
yt-dlp, FFmpeg) that handle networking and media processing on Orbit's behalf. On Linux,
Orbit also uses services of your desktop session (the systemd login manager and the desktop
portal for power management, your file manager, and the desktop's clipboard manager) only
on your own device. These
components do not independently transmit data beyond what is described in Section 5.
